How to export WG JSON

Build two public characters first. Old UI: amba.wandersguide.site. New UI: wgui.wandersguide.site. Same WG account on both. Turn on Public Character (Home → Options) before you export. Details are on the WG page.

  • Old UI: Open Characters. On that PC’s card, open the options menu (the menu with Create Copy). Choose Export to JSON. Save the .json file.
  • New UI: Open the character sheet. Open the Character menu. Choose Export JSON. Save the .json file.

Export each of your two PCs. Do not upload a Pathbuilder file, a PDF, or the GM API key.

Drop files here

Two JSON files per person. We store a zip of each one. You can delete your own files with ×. The GM later downloads four of the eight from this list after we pick on Discord, then unzips to import.

    Example

    Merry-Anchor exports scout.json from old UI and cleric.json from new UI, then drops both here. The list keeps scout.zip and cleric.zip.

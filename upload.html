WG JSON

Private character fallback

If your WG character is public, you probably do not need this page. Once you save the public sheet link on the WG page, the character is already read-only in the party pool, and AMBA can import from the WG link. Upload a JSON file only when you want to play a character that is staying private.

Log in on this site before uploading. This page only stores WG character export files for private-character fallback. It does not ask for AMBA, WG, Owlbear, Discord, or API-key passwords.

Public link first

The easier path is to make your character public in WG and save the public sheet link on the WG page. That puts the character on Signup for the group to see, keeps the sheet read-only for everyone else, and gives AMBA enough to import from the WG link. No JSON upload needed.

If the character is private

If you want to keep a character private, export that character as Wanderer’s Guide JSON and drop the file here. The GM can use the uploaded JSON for the character you are actually playing.

  • Old UI: Open Characters. On that PC’s card, open the options menu (the menu with Create Copy). Choose Export to JSON. Save the .json file.
  • New UI: Open the character sheet. Open the Character menu. Choose Export JSON. Save the .json file.

Upload WG JSON exports only. Pathbuilder characters should be imported into WG first, then exported from WG. PDFs and API keys do not belong here.

Drop files here

Drop a WG JSON file here only for a private character you intend to play. The site stores a zip of each file, and you can delete your own uploads with the delete button. After the group picks the warmup party, the GM downloads any needed private-character files, unzips them, and imports them into AMBA.

    Example

    Merry-Anchor makes a scout public and saves the sheet link on WG, so no upload is needed for that one. Their secret backup character stays private, so they export cleric.json from WG and drop it here. The list keeps cleric.zip.
